❓ 使い方

このアプリは？

金城学院高校の日本史（第24〜50章・27単元・481問）の一問一答です。問題を見て答えを思い出し、自分で ◯✗ をつけます。

📝出題

  1. 出題する単元にチェック（右の「⭕3/18」は、最後に正解した問題の数／単元の問題数）
  2. 出題順（シャッフル／単元順）、出題形式（説明→用語／用語→説明）、苦手のみ を選ぶ
  3. カードをタップ → 読み上げと答え → 「◯正解した」「✗不正解だった」
  4. 上の「✗間違い一覧」で、その回に間違えた問題をいつでも見られます

📌 続きから再開

1問ごとに進み具合を保存しています。途中で画面が消えて最初にもどっても、「▶ 続きから再開」で続きからできます。

⭐苦手

これまでに間違えた回数が多い順です。タップすると「学習のあと」が開きます。

🔍検索 と 学習のあと

  • 漢字・ひらがな・問題番号・自分のメモで探せます。「⭐苦手だけ」「📝メモあり」「❌学校テストで間違えた」などでしぼれます
  • 問題をタップ → 何回・正答率、いつ・どの形式で⭕❌だったか、苦手ランキングの順位
  • 学校のテストが返ってきたら、その問題を探して「⭕テストで正解／❌テストで間違えた」を押し、✏️ふり返りメモ（なぜ間違えたか）を書きましょう
  • 「🔗ほかの問題の説明文に出てくる」で、つながりのある問題も確かめられます
  • 「▶この問題を練習する」で、その問題だけすぐ出題できます

📋 先生に報告

「⭐苦手」タブか結果の画面から。LINEで先生に送る／👪おうちの人に送る（先生に転送してもらう）／📱QRコードを塾で先生に読み取ってもらう、のどれかで送ってください。

プリント作成

いちばん上の「プリント作成」タブで、範囲をえらんでシャッフルしたプリント（問題編・解答編）を印刷できます。「苦手問題のみ」にもできます。

おすすめの使い方

① テスト範囲の単元を「説明→用語」で1周 → ② 「苦手のみ：はい」で ✗ がなくなるまで → ③ 「用語→説明」で説明できるか確かめる → ④ 苦手をプリントにして紙に書く

うまく動かないとき

  • LINEで開いたときは「…」→「Safariで開く」（Androidは「デフォルトのブラウザで開く」）。LINEの中とSafariでは記録が別々になるので、いつも同じほうで開きましょう
  • 古い画面のままのときは、アドレスの最後に ?v=21 をつけて開き直す（タイトル横が「v2.1」なら最新）
  • 日時つきの記録は v2.1 から残ります（それより前の記録は回数だけです）
  • 「記録をリセット」を押すと、苦手・学習のあと・学校テスト・メモがすべて消えます
